# Demo data

Invented orders for the sample company in the app (Settings, Sample data, Load sample data). Every name, number and shop is made up.

## whatsapp/

Fake WhatsApp order screenshots. Drop one onto the import box on the Quotations page.

| File | What it shows |
|---|---|
| 01-ace-mobile-sp.png | A list with product codes and plain names, asks for the wholesale price |
| 02-digital-zone-jb.png | Malay and English, phones by name and colour, asks for the dealer price |
| 03-techpoint-kuching.png | Chinese, codes mixed with Chinese product words, distributor price |
| 04-gadget-corner-ipoh.png | An unsaved number, one long sentence, no list |
| 05-mobile-hub-melaka-photo.png | A product photo in the chat, quantities in the text |
| 06-aman-telefon-kb.png | Malay, quantity before the product name, no codes |
| 07-phone-world-penang.png | Two items the sample shop does not sell (iPhone, Samsung) next to three it does |

## products-sample.csv

The sample product list as a file you can import on the Products page: one row per product, `price` is the standard price, `Wholesale`, `Dealer` and `Distributor` become price lists.
